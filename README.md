# 올팍 나우 (OlPark Now)

실측 입출차 데이터로 현장 상황을 보정하는 **올림픽공원 공연일 주차 운영 의사결정 지원 시스템** — 한국체육산업개발(주) 공공데이터 기반

**서비스:** https://bugeon151.github.io/olpark-now/ · 소스: https://github.com/Bugeon151/olpark-now

## 무엇을 하나
- **운영 대시보드(주 사용자: 기관 운영자)**: 공연 일정·같은 달 평소 패턴·KSPO DOME 공연일 68일 관측으로 시간대별 예상 재차(중간·범위), 혼잡·만차 위험 시각, 임시 주차 필요 규모, 출차 인력 배치 시각과 시간대별 권장 조치
- **나우캐스트 검증**: 당일 실측 재차로 1~3시간 뒤를 보정 예측하는 과정을 과거 공연일로 재현
- **관람객 안내(2차 채널)**: 도착 권장 시각, 구역·대중교통 안내, 시차 귀가
- **검증·데이터**: 정확도·신뢰구간·경보 성능, 데이터 품질 발견 사항 · 국문/영문

## 핵심 결과 — 2025년 입출차 2,411,225건 전수 집계
동2·남2·북2문 1,975,475건으로 시간대별 재차를 복원(원천 수록이 완전한 240일). 공연일 15~22시, 1~3시간 뒤 예측 MAE(대).

| 방식 | 월 단위 교차검증 | 10~12월 홀드아웃(1~7월 학습) | 홀드아웃 MAPE |
|---|---:|---:|---:|
| 평균 프로파일(같은 달·요일유형) | 766.1 | 873.9 | 47.9% |
| 전주 같은 시각 | 429.1 | 634.3 | 47.5% |
| 현재값 유지 | 388.6 | 429.9 | 54.8% |
| 사전 예측(공연·달력·기상) | 380.6 | 531.4 | 33.7% |
| **나우캐스트** | **162.1** | **179.0** | **14.5%** |

- 개선폭 95% 신뢰구간(홀드아웃, 공연일 부트스트랩 2,000회): 현재값 유지 대비 184.4~323.3대, 평균 프로파일 대비 473.5~917.2대
- 홀드아웃 혼잡(70%) 경보: 재현율 0.792·정밀도 0.905(현재값 유지 0.631·0.605), 만차(90%) 위험측 재현율 0.894
- 복원 재차와 기관 연계 데이터 `주차대수` 상관 0.952
- 독립 검증(2024년 7월 215,528건, 날짜 단위 31회): 나우캐스트 147.1대 대 평균 프로파일 332.5대

## 데이터 품질 발견
- 2025 입출차: 매월 말일 0건, 8·9월은 일평균 약 2.2천 건(다른 달의 23%), 11·12월은 1~7일만 수록 → 완전한 날만 사용(`model2025.VALID`)
- 공연일 28일·117시간 동안 재차가 공개 수용 2,200대 초과(최대 3,563대, 2025-04-06)
- 주차장 혼잡도 정보 등록시간의 분·초 자리에 월·일이 기록됨(시 단위만 유효)

## 구조
```
index.html            배포용 단일 페이지(demo/build.py 결과)
data/raw/y2025/       2025 시간대별 그룹 집계(hourly.csv), 게이트별 집계, 메타, 기상, 연계 데이터, 혼잡도
data/raw/             2024-07 집계, 월별 주차, 공연·공연장, 2025 공연 회차
data/derived/         구역별 혼잡도 통계
model/                model2025.py(2025 학습·검증) export2025.py, 2024: train.py nowcast.py robust.py export.py
demo/                 template.html + model.json → build.py
tests/                데이터 무결성·지표 재현 테스트(pytest, 19개)
```

## 재현
```
pip install numpy pandas scikit-learn matplotlib pytest
cd model && python3 train.py && python3 nowcast.py && python3 robust.py && python3 export.py
python3 model2025.py && python3 export2025.py && cd ..
python3 demo/build.py && cp demo/index.html index.html
python3 -m pytest -q tests
```
